---
name: next-slice
description: Use when Mishi says "keep going", "next step", "build the next part" or similar in a project that has a PLAN.md.
---
1. Read SPEC.md, PLAN.md and PROGRESS.md.
2. Pick the next unfinished slice. Say in one sentence what you'll build.
3. Build it. For Mac or iPhone apps, run `xcodegen generate` after adding files.
4. Build and run the app, and check it works by using it: Simulator tools for apps, a browser for web. For anything visual, follow the design-check skill.
5. Fix what you can. If something has failed twice, stop and explain.
6. Report: what changed (2–4 plain sentences), exactly how to try it, and anything you're unsure about.
7. Update PROGRESS.md. Wait for her OK, then commit with a clear message and push.
